# Portfolio audio

This folder contains the MP3 previews played on Eli Konoff's portfolio website.

Upload these three files *directly into this folder* (not inside an extra nested folder):

- `jungle-soundscape.mp3`
- `drifting-dog.mp3`
- `indomitable.mp3`

The website automatically shows audio controls once each corresponding file is uploaded. The original WAV masters should be retained elsewhere.
